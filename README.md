# Haru2.0

An original Minecraft 1.8.9 Forge client targeting Java 8 and PojavLauncher.

## Goals
Recreate the visible organization and user experience of the Haru Client using original, independently written code.

## Module catalog
The initial catalog follows the categories and names identified from reference screenshots: Settings, Combat, Player, Other, Visuals, and Exploit.

**Important:** catalog entries are registration placeholders until their individual behavior, settings, and UI are implemented and tested. A listed module is not yet a promise that its feature works.

## Build
The project uses ForgeGradle 2.1, Minecraft 1.8.9, and stable_22 mappings.
